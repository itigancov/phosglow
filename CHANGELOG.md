## [1.0.0] - 2026-11-27

### Added

- The Palette: one set of named colours that every Port is rendered from.
- Ports for Ghostty, Claude Code, herdr and iTerm2.
- The CRT Shader for Ghostty.
- `install.sh`, with `--dry-run` and `--uninstall`.
- Plugins for Claude Code and herdr.
- `tools/test.sh` and CI.
